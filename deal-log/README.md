# Deal log

`deal_log.csv` is the running record of every deal you screen or underwrite. Open it in Excel or Google Sheets.

Log a row for every deal, including the ones you pass on. Revisit the `what_happened_later` and `date_reviewed` columns a few months later. Comparing your calls with outcomes is how you build judgment.

Delete the example row once you add your first real deal. Use public listings only.
