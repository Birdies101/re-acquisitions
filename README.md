# Real Estate Acquisitions Portfolio

Underwriting models, deal write-ups, and automation tools for real estate private equity acquisitions, with a focus on value-add and opportunistic strategies in the multifamily housing space.

> Status: Phase 0 (setup). Replace the bracketed placeholders below as you build.

**Focus:** Multifamily housing in Orlando, Miami, and Central New Jersey
**Author:** Luke Kodila | https://www.linkedin.com/in/luke-kodila/

## What is in this repo

| Folder | Contents |
| --- | --- |
| `models/templates/` | Clean base underwriting models (multifamily, multi-tenant, development) |
| `models/deals/` | One model per deal analyzed |
| `writeups/memos/` | IC-style investment memos |
| `writeups/case-studies/` | Value-add and opportunistic case studies |
| `writeups/market-notes/` | Submarket briefs and market theses |
| `projects/` | Automation tools (screener, rent roll extractor, debt engine, and more) |
| `deal-log/` | Running log of every deal screened, with decision and outcome |
| `data/` | Public or synthetic data only (raw downloads are git-ignored) |
| `reading-notes/` | One-page summaries of books, chapters, and reports |
| `docs/` | Conventions and the project index |
