# Model templates

Clean, reusable base models. Copy a template into `models/deals/` before using it on a deal. Do not edit the template for a single deal.

Planned templates:

- [ ] Multifamily acquisition and value-add model
- [ ] Multi-tenant commercial model (rent roll, TI, leasing commissions, rollover)
- [ ] Development pro forma with draw schedule and interest reserve
- [ ] Equity waterfall (preferred return, catch-up, promote tiers)

Follow the Excel standards in [`docs/conventions.md`](../../docs/conventions.md).
